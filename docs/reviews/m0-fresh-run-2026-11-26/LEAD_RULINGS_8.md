Under this, as the listing describes them: `oracle_any_literal` (both outputs) and `best_generic_in_shape` are not read; `MF_printform_cv` counts; `BEST_generic_cv` counts already. **The auditor of the pooling script confirms each description from the committed code; a field he cannot confirm as using the scored items' answers counts.** `share_of_level` in the output of `a3_shortcuts.py` is not a hit share; hits are read from `hit`. This ruling leans toward passing for the two fields it leaves unread and is reported as such.
