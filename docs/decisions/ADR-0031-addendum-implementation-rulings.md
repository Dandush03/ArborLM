# ADR-0031 addendum — rulings for the implementation of P10-I-S6 (2026-11-19)

Rulings of the scientific lead (Claude Fable 5.2) on readings of ADR-0031 that its first implementation audit left open (`docs/reviews/p10-i-s6-implementation-audit-2026-11-19/AUDIT_P10IS6_CORE.md`, arbor-auditor subagent, Claude Opus 5.5; verdict CORE SOUND AFTER LISTED FIXES at commit `7b1383a`). They are made before any registered or calibration value of this study exists: no parent is trained, nothing is downloaded, no rehearsal has run. They change no threshold. Where a reading could move a label, the reading less favourable to the memory is taken, and an engineering failure is never allowed to become a scientific label. They are put to the human lead for confirmation with the run decision; he can overrule any of them before Decision 2. ADR-0031 itself is not edited. `Astra review: NOT_PERFORMED`. Claude review is not Astra review.

## Rulings

1. **(L1) How far G17 reaches.** R16 is NOT EVALUABLE whenever line P is row 2 (MEMORY UNSTABLE (FAILED CELLS)) or row 1 by cause 1, 2 or 3 (the integrity causes and a failed dense cell that a rule reads). Under cause 4 alone (the dense floor at a reading rung other than rung 0) R16 is still computed, by its own rule and its own rung-0 dense floor: cause 4 is neither an integrity state nor a failed-cell state, and R16 reads rung 0 only. A favourable replication readout never stands beside a failed-cell or integrity label. (Audit R1.)
2. **(L2) An undefined intervention in one cell.** A COLLAPSED cell, or a non-finite P_used or X_mean read in one cell, leaves that control's mean undefined and fails the control's condition (F2 or F3) as a whole. No mean is taken over fewer cells. This is the implementer's reading; it is the one less favourable to the memory.
3. **(L3) A missing BASE record** is ENGINEERING STOP — INCOMPLETE REGISTRY and the analysis refuses. A BASE record that is present with a non-finite value is NOT EVALUABLE, cause 1. A missing `used_slots` statistic is likewise INCOMPLETE REGISTRY, never "not COLLAPSED" (audit A1).
4. **(L4) The panel walk and the article numbers.** The panel walk starts at rank 8,192 with every span of the shared panel ledger and P10-I-S3's two panels in the excluded set (the audit shows this equals "continuing after" P10-I-S3's panels). Article 0 is the text before the first heading; articles are numbered after the exclusion, articles without a chunk included.
5. **(L5) The old-parent anchor OA.** OA's convergence state is read from the run's own improvement δrun only: OA has no run at the rate of rung −1, so it has no envelope. OA enters no label.
6. **(L6) Tag 2 of the trend line.** The rule is the definition: tag 2 applies exactly when HELD(0) is false. The sentence of section 12.6 that tag 2 occurs "exactly when R16 is not REPLICATED" is descriptive and is wrong where R16 is NOT EVALUABLE while HELD(0) is true (its rung-0 dense floor, or ruling 1); it is not a rule.
7. **(Audit R2) A calibration that is not interior** after the registered extensions is an ENGINEERING STOP, as section 8 says: the rate table raises it, and the freeze refuses unless every interior flag at every rung from −1 to k_max is true for both arms. No registered run carries a rate at the edge.
8. **(Audit R3) Integrity equalities in the analysis are exact on every platform.** They compare recorded numbers. The platform of record conditions only the gates that recompute; results are registered on the platform of record only.
9. **(Audit R4, R5) The parent and data commands.** No new parent is trained before an identity record shows nine bitwise-equal digests for the nine old parents; an existing parent file is accepted only if its recomputed digest equals the stored one, otherwise it is kept aside and retrained with the attempt logged. The data command does everything the audit's R5 (a) to (g) lists. The download rows are written into the project's one download ledger, `docs/reviews/p10-design-2026-11-15/DOWNLOAD_LEDGER.md`, in its own format with its running total; no second ledger file is created. (That file is the ledger of record, which earlier studies' code appends to; appending rows to it is its purpose and is not an edit of a record.)
10. **(Audit A2, A3) Precedence and what is printed.** A non-finite replay after a finite enabled read is NOT EVALUABLE by section 12.2 item 2 (row 1), not a failed cell. A non-finite enabled value at one snapshot makes L NOT DETERMINED at every rung that run serves, and nothing is printed for them.
11. **(Audit A4) Resume and prefix identity** are compared on the bytes of every tensor of the state (so −0.0 and +0.0 differ), not with a value comparison and not on file hashes.
12. **(Audit A7, A11) Seeds in tests and templates.** Synthetic backbones in tests use test-range seeds (952001–952999), not P1's 42–44; the planted toy uses its allocated value 330793; the control memory `Memory("learned_tree", 201)` is not constructed for new parents (G9), unless the identity gate itself needs it, in which case 201 is the declared re-use and the report says so.
13. **(Audit A8, A9, A12, A13)** In registered mode the analysis asserts 27 cells and 27 OA cells and never reduces a denominator; the descriptive output of section 12.5 is complete (per-parent envelope δ, X_mean_dense, calibration against registered convergence states, the statistics at 8,192); no test depends on the tests' directory being a git work tree; a partial item directory is kept aside on restart, never deleted.
