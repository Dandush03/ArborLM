# ADR-0024 addendum (quiet rule) — rulings F1 to F7 after the implementation audit of 4bb38c7

**Status: RULINGS, taken by the lead under the human lead's delegation for P10-I-S1 (see the addendum's A0). They follow the independent audit of the implementation (`experiments/_scratch/audits/AUDIT_P10IS1_QUIET.md`, verdict READY AFTER LISTED FIXES); this file records them and is not itself reviewed. No registered value of P10-I-S1 exists and the calibration's sealed values are unopened. Nothing here changes a scientific threshold, label, seed, cell, arm, grid or run length. No registered stage is approved by this text.**

`Astra review: NOT_PERFORMED`

Where this file and the addendum differ on the quiet condition, this file applies. Not Astra validation and not human approval.

| # | Ruling | Reason |
|---|---|---|
| F1 | At every baseline sample, quiet reading, in-measurement tick and end check, any process whose command line contains `shell-snapshots/snapshot-` (the shell of a tool call of ANY Claude session) outside the stage's own process chain fails the reading, and the set of Claude processes (application and CLI markers) must stay the same through a baseline attempt and from a stage's quiet reading to its end check; at a stage a discard on this cause is PAUSED — NOT SILENT, a status of its own that never counts towards NOT MEASURED. | The lead's silence was not observed at all; a tool call or another session passed every condition. With this the open-and-silent choice is checked by code, not assumed. |
| F2 | The `"pytest" not in command` exemption is removed from the study-process check; a study command line containing `pytest` is another study's process. Tests that need an exemption pass an explicit test-only allowance (`Probe.allow`, `other_study_processes(allow=...)`). | A multi-core test run of another study was invisible to the baseline and the stages. |
| F3 | Low Power Mode is read from both `powermode N` (this Mac; 1 is Low Power) and `lowpowermode N`; if neither is present, or the power-source line is missing, the reading fails (never a pass). | This Mac prints `powermode 0` and no `lowpowermode`, so the old condition could never fail. |
| F4 | One baseline per study: the command works only in the study's fixed root (`<experiments>/P10IS1-quiet-baseline`, `first/` for every session of the first baseline, `second/` only through `--replaces` with one of the four reasons); it refuses any other directory holding a baseline record, a new first baseline once `first/` is ACCEPTED, and a second one without the reason; a record that is not ACCEPTED (not settled under the rule) is continued, never restarted elsewhere; every attempt is listed in the record (a second baseline also lists the first's attempts); the freeze, when the root exists, requires the committed record to be the root's first ACCEPTED record or its second whose reason file predates its first sample. | Taken once per directory allowed L to be re-rolled and the preferred record copied. |
| F5 | `rehearse --counting --resume` refuses a `--plan` whose SHA-256 differs from the one the run directory was started with (`counting_start.json`). | Stages completed under one plan could be named by a record of another. |
| F6 | The conditions of A3.3 are read at every 10-s tick of a quiet stage's measurement, not only at the start and 120 s after the end; a failed tick discards the reading under the status of F1 (NOT SILENT) when the cause is silence, else under F7's. | A tool call that starts and ends inside a measurement falls on some items and not others and was seen only if it lasted to the end check. |
| F7 | A failed end check, or a failed in-measurement check, does NOT count towards NOT MEASURED: it is PAUSED (NOT SILENT, or MEASUREMENT DISCARDED for any other cause) and the stage waits again and measures again inside the SAME bounded wait window; only a session with no quiet reading at all counts as PAUSED — QUIET CONDITION NOT MET. The six-session decision refuses sessions of any other status. | NOT MEASURED removes the MC-T condition from the CAPACITY rows, which favours the store; no machine-noise path may lead there. |

**Accounting ruling.** The incomplete quiet rehearsal's non-waiting work (ledger `experiments/P10IS1-rehearsal-P10IS1-counting-quiet-20261119T184025-ledger.json`: gates 0.4124 s, timing 2,478.3775 s of which 4 x 600 s = 2,400 s are polling sleeps, train 3,849.9298 s, ladder 325.1884 s, evaluate 281.0370 s, baselines 11.2299 s) is 4,546.17 s = 1.2628 h; the timing measuring is taken as the ledger's figure minus the four 600-s polling sleeps, an upper bound because real sleeps overshoot slightly. It enters the charged-before-freeze total H_c that the candidate plan reads through the projection (`project --charged-hours 1.2628`, added to every `--ledger`). The ledger's own `pre-freeze` entry (24,133.35 s = 6.7037 h) is the copied earlier H_c and is not added again.
