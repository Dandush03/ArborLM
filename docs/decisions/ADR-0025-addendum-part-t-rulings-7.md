# ADR-0025 addendum: Part T rulings 34 to 37 (seventh addendum)

Status: rulings of the lead coordinator after the sixth check of 4548d26 + e78e423 (C1' and C3' closed; C2' partly open as C2''). They bind like the ADR and the earlier addenda (none is edited). Recorded by the implementer from the coordinator's message; not a human-lead approval record beyond what the coordinator states. `Astra review: NOT_PERFORMED`.

34. **A begun unit is never retrained silently (C2'').** Before a unit trains, `calibrate` appends and commits (the same signed single-line commit of the log file alone) a `unit_begin` line naming the unit and the session identity. A unit with a committed `unit_begin` and no committed `unit` result line is never retrained silently: its state is set aside and the run stops until a committed `UNIT_DECISION.md` names the unit. A failed `unit_begin` commit stops before training.
35. **The log is checked against the pushed copy.** The config records the remote URL and branch the log is pushed to (`[calibration_log]`; the human lead fills them; empty refuses). At every `calibrate` start and resume, at `candidate-plan` and at `freeze`: the upstream `@{u}` must exist, its remote's URL must equal the recorded URL, and the log's committed history at HEAD must descend from the log at `@{u}` with every line of the upstream log an unchanged prefix. `calibrate` (run) refuses unless the open line is in `@{u}`; `candidate-plan` and `freeze` refuse unless HEAD's log commit is itself in `@{u}` (the finished log is pushed). The code makes no network call: it reads the remote-tracking ref; the lead fetches and pushes. `git branch -r --contains` alone is no longer accepted.
36. **Stated residual (replaces the single line of ruling 32).** (i) Rewriting unpushed unit commits within one uninterrupted session together with deleting state, and (ii) a force-push or a hand-edited remote-tracking ref. Both leave the pushed history or the reflog inconsistent with the final record and are the lead's to disclose; the lead pushes the log after each session stop, so that (i) is bounded to one session.
37. **Advisories adopted.** Every git subprocess has a 60 s timeout (a timeout is a commit failure) and a non-interactive environment (`GIT_TERMINAL_PROMPT=0`, no askpass or pinentry wait). The identity is checked before the first record of a session is written, also on the first run after `--open`. The session identity also carries the interpreter path, `sys.prefix`, a hash of the installed packages and the values of the `PYTORCH_*`, `OMP_*`, `MKL_*` and `VECLIB_*` environment variables; a resume under different values is refused. `candidate-plan` checks the plan's own projected total against `study_budget_hours`. `calibrate` refuses while `study_budget_hours` is 0.0.
