## Falsifiable question and interpretation contract

Can a newly trained instance of the existing hierarchical memory add reliably useful predictive capacity to an entirely frozen, previously trained backbone within 512 updates, and how does it compare with an equally parameterized dense addition trained on identical examples with the same optimization budget?

The narrow hypothesis is that the memory produces a mean held-out improvement of at least 0.005 nats/byte over its unchanged parent, that the improvement depends on trained key/value associations at the same sensitivity, and that it is reliable across the registered parent/initialization grid. A separate criterion measures competitiveness with a dense adapter. Each criterion and its failure interpretation is fixed below. This is a descriptive, bounded screen; no significance claim, population noninferiority claim or universal proof/disproof follows from its thresholds.

Freezing all backbone parameters removes *concurrent backbone optimization* as an explanation for P4 gains. It does not make the backbone representation independent of its historical training, identify semantic knowledge, or establish hierarchy's value versus flat memory. Fresh memory is trained from initialization; the unused, frozen memory carried in P3 control checkpoints is not reused. This is adapter training, not continuation of a learned P3 memory trajectory.

## Exact model and freezing contract

Extract only the original backbone components: token embedding/tied output weights, positional embedding, both transformer blocks, final LayerNorm and causal mask. Retain exact tensor bytes and original forward mathematics from P3; no reinitialization, dtype conversion or changed LayerNorm/activation. Backbone parameter count is **27,392**. Drop the unused parent memory from the new P4 model; preserve the original checkpoint unmodified on disk. Baseline stores only these backbone parameters, all frozen, with no optimizer.

Both trainable additions act at the existing location after block 0 and before block 1. Every backbone parameter, including biases, all LayerNorms and tied embeddings, has `requires_grad=False`, remains absent from the optimizer, and must stay bitwise identical throughout. Model buffers/masks also stay unchanged. Do not detach the augmented residual or disable autograd through the frozen second block/final norm/output: gradients with respect to the addition must pass through these frozen operations. No additional trainable output head, normalization, bias, projection, temperature or backbone adapter is allowed.

**Hierarchical memory:** reuse the unmodified `Memory("learned_tree", seed)` retrieval and fusion from ADR-0005. Independent 4096×16 keys, 4096×32 values, biasless 32→16 query and 32→32 output matrices, scalar gate, 16×16 learned router. Fixed 16 partitions of 256 slots, top-2 branches then global top-8 values among 512 candidates, normalized cosine/temperature 0.2, branch log-softmax prior, stable ascending-ID tie handling, ordinary gradients through selected scores/values only. No topology change, straight-through estimator, warm-up, locality loss or new normalization. Initialize matrices normal(0,0.02), component generators seed+1000 keys, +2000 values, +3000 query, +4000 output, +5000 router; gate=-2.0. All **198,401** addition parameters train. Total stored model parameters: **225,793**.

**Dense adapter:** `h_next = h + sigmoid(g) * W2 * GELU(W1*h)`, with biasless W1 of shape (3100,32), biasless W2 of shape (32,3100), exact GELU (`approximate="none"`), scalar g initialized -2.0. Initialize W1 normal(0,0.02) with independent CPU generator seed+3000 and W2 likewise seed+4000. No extra scale, bias, normalization, dropout or residual branch. This gives `3100*32 + 32*3100 + 1 = 198401` genuinely used trainable parameters, exactly matching memory without padding/dummy parameters. Total stored parameters: 225,793.

Generators are isolated from backbone construction, batch order and global evaluation RNG; the same new seed produces identical addition tensors across all parents. Initialization algorithm and gate match where meaningful, but function/output variance differs across architectures; report step-0 losses explicitly. Matching trainable count, examples, optimizer and updates does not match active compute, search cost, conditioning, initialization noise or optimal hyperparameters.

## Prespecified analysis and criteria

For parent p and initialization r define B_p=frozen-baseline NLL, H_pr=final memory NLL, A_pr=final dense-adapter NLL, V_pr=memory-values-shuffled NLL. Define C=B-H (memory capacity gain), D=disabled-memory-H, P=V-H (association sensitivity), C_dense=B-A, Q=A-H (positive favors memory). Correct freezing requires disabled-memory=B and disabled-dense=B bitwise, hence **D=C exactly**; they are not independent evidence. Also verify Q=C-C_dense within 1e-12.

Report all initial/final/intervention NLLs and gains, mean, sample SD, minimum, maximum and sign counts for 27 paired cells, and separately 9 unique baseline losses. For each of the 9 parents report means across all three seeds and all seed values; do not select the best seed. Report per-seed means across parents and marginal B/O summaries descriptively. Include every run's final-minus-initial loss, both variants' improvement/worsening counts, timing/RSS, training budget, routing and parameter measures. Correlation through shared parents/data/seeds invalidates treating 27 comparisons as 27 independent backbone replications; no p-values or independent-replicate confidence intervals.

Three primary descriptive flags, fixed before any P4 model outcome:

1. **Added predictive capacity:** mean C ≥ 0.005, at least 22/27 cells with C > 0, at least 8/9 parents with mean C > 0, and mean final H < mean initial H.
2. **Useful slot-association dependence:** mean P ≥ 0.005, at least 22/27 cells with both C > 0 and P > 0, and at least 8/9 parents with mean P > 0.
3. **Within dense quality tolerance:** mean Q ≥ −0.005, at least 22/27 cells with Q ≥ −0.005, and at least 8/9 parents with mean Q ≥ −0.005. This is a screening tolerance, not a statistical noninferiority test.

The stricter parent counts guard against a few favorable backbones dominating a pooled mean. Thresholds are design choices, not estimated significance levels. Failure of any clause makes its flag false; preserve all clauses, numbers and opposite-sign trajectories. All 63 cells and engineering checks are required for a complete study; failures produce incomplete evidence, not silently reduced denominators.

Flags 1 and 2 support only reliable useful memory contribution under this frozen-backbone/fixed-data/budget/panel definition. Flag 3 additionally supports competitiveness with this particular dense adapter at matched trainable count and update budget. All three are required for the composite P4 success label. If capacity/dependence pass but dense tolerance fails, retain the capacity finding and state that dense is the stronger tested alternative. If C improves but P does not, additional capacity may exist without demonstrated dependence on slot associations. If training only repairs a harmful random addition and C fails, useful capacity is not established. If flags fail, reject these registered criteria for this configuration; do not infer universal impossibility.

Secondary, nonessential descriptive flag: memory advantage over dense if mean Q ≥ 0.005, at least 22/27 cells with Q > 0, and at least 8/9 parents with mean Q > 0. Do not promote this secondary flag to replace a failed primary flag. Report routing gradients/movement and usage without inventing a post-outcome collapse threshold. No result here establishes hierarchy-specific advantage (flat/fixed-memory comparisons remain absent), semantic storage, more-data benefit, optimal tuning, an active-compute frontier or broad generalization.

## Authorized design review before implementation

Root approves the exact design above under the standing human exception, subject to engineering preflight. Reasons: using all nine parents prevents favorable-backbone selection; complete freezing plus exact disabled-baseline equality isolates the added trainable component; genuinely parameter-matched dense controls distinguish memory contribution from generic added capacity; a fresh panel and fixed step-512 endpoint avoid reusing the evidence that motivated the hypothesis; paired seed and parent statistics and the 8/9 parent conditions make the intended reliability claim explicit without asserting independence. The dense adapter's width follows exact parameter arithmetic, not model outcomes. Repeated training on the same data and unchanged retrieval isolate this question while preserving P1–P3.

Approved scientific choices include fresh memory seeds 401, 402 and 403, the exact adapter architecture and initialization, optimizer reset for new parameters only, the original order repeated over two epochs, fresh panel ranks, thresholds, parent aggregation and the 1,800-second ceiling. Remaining prerequisite is engineering evidence, not an unrecorded scientific choice. No Astra review occurred. P5 learnable topology, P6 capacity scaling and P7 SSD remain candidate phases requiring separate evidence/design/human decisions; this ADR authorizes none of them.
