# Parameter changelog

Every change, after a specification's approval, to a parameter, limit, cap, rule of reading or procedure of a study. Kept at the human lead's request of 2026-11-19: "we can always change parameters as long as we add it to the changelog and make them reproducible".

**What may be changed, and when.** A parameter may be changed with a recorded reason before the quantity it governs has been observed in a registered run. Nothing is changed after a registered value has been seen, and no registered threshold is relaxed (AGENTS.md; `docs/EXPERIMENT_PROTOCOL.md`). Each row says whether any governed value had been observed. A row is a pointer: the binding text is the record it names. New rows go at the end; rows are never edited or removed, and a correction is a new row.

Started 2026-11-19. Earlier changes are in each ADR's own rulings and review-record sections (for example ADR-0029 sections 18 to 20) and are not repeated here. Branches named below hold the record until the study's branch is merged.
